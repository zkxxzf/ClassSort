## 项目简介

这是一款由一线教务老师发起、借助 AI 编程辅助工具开发的**智能分班软件**。作者长期身处教学管理一线，深知每学期分班工作给教务老师带来的巨大压力——手动操作耗时耗力、难以兼顾各项均衡指标、容易引发家长质疑。为解决这一痛点，作者利用 AI 辅助编程技术，将多年教务经验转化为算法逻辑，打造出这款**完全离线、开箱即用**的分班工具，希望能为广大教务同仁减轻负担。

软件采用多目标优化算法，在数秒内完成数百名学生的均衡分班，确保各班在总分均分、单科均分、分数段分布、性别/类别比例等维度上达到极低偏差，同时支持重点班/普通班分层分班、捆绑分班、互斥分散等教务常见需求。

## 班型分层分班（v1.10 核心升级）

本版本最重要的算法升级——不同班型（重点班/普通班等）**完全独立分班、独立计算偏差**：

- **重点班**只在重点班名额内分班，均分偏差只在重点班内部比较
- **普通班**只在普通班名额内分班，均分偏差只在普通班内部比较
- 各班型分段均衡独立计算（重点班内三段、普通班内三段）
- 日志和统计中分别显示各班型组内偏差

例如：设置重点班为前 100 名（1、2 班各 50 人），则分班算法只在这 100 名学生内优化 1、2 班的均衡，剩余学生进入普通班单独优化。

## 算法原理

分班引擎采用分层优化策略，在毫秒级内完成高质量分班：

1. **预处理**：约束构建、预设班级、捆绑代表、班型筛选
2. **初始分配**：蛇形分配（snake draft）保证分段均衡
3. **定向优化**：高均分班 ↔ 低均分班定向换班
4. **全局贪心**：成对换班，最小化加权偏差成本
5. **模拟退火**：跳出局部最优
6. **3-way 循环交换**：突破两两交换局限，消除 0.5 分差
7. **终局微调**：逼近 0.01 均分偏差

**班型模式**下，所有偏差计算和优化操作均在班型组内进行，组间差异不计入成本。
